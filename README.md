# EasyNewTab

Chrome 新标签页扩展：中间是搜索框，下面是常用网站，侧边栏放书签和历史。

## 功能

- **搜索** — 输入网址直接跳转，否则用当前搜索引擎搜索，带联想词（方向键选、回车确认）。
  引擎可切换：Google / Bing / DuckDuckGo / Yandex / Bilibili / GitHub（后者无联想）。
- **常用网站** — 最多八个，取自本机浏览记录。
- **书签** — 点击展开文件夹或打开书签；文件夹右键（触屏长按）可新建 / 重命名 / 删除；
  树下方空白处右键可新建顶层文件夹；书签行悬停出现 ✕ 删除。
- **历史** — 按天分组，点击打开，✕ 删除。
- **侧边栏** — 拖中间的分隔线调宽，拖到底即收起，按 `s` 显隐。
- **设置** — 在扩展页打开「选项」：书签是否在新标签页打开、是否显示「其他书签」、
  侧边栏停靠方向。

## 快捷键

`/` 搜索框 · `p` 搜书签 · `s` 侧边栏 · `b` 书签面板 · `h` 历史面板 · `Esc` 清空搜索框
